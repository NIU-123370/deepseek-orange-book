## 这本书讲什么

《DeepSeek Harness 橙皮书》是一份面向普通使用者和 Agent 开发者的实践指南。作者以 DeepSeek Harness v0.1 开发者预览版为对象，结合官方仓库、官方文档、683 篇设计笔记和本机实测，记录了它在发布初期的安装、使用、成本、权限、扩展机制和工程取舍。

可以把 DeepSeek Harness 理解为两样东西：

- 一个开箱即用、能读写文件和执行命令的本地编码 Agent；
- 一套可以替换模型、工具、插件和运行方式的 Agent 框架。

它不是单纯的聊天网页。程序运行在本机，但模型推理发生在远端；被 Agent 读取并用于推理的内容会发送给模型服务。

## 核心结论

1. **新手先用标准模式。** 四种模式不是简单的强弱档位，而是面向不同工作方式。标准模式适合绝大多数日常任务；PTC、极简和创造模式都有明确的特殊用途与代价。
2. **默认权限相对克制。** 默认沙箱只允许写入已登记的工作区和系统临时目录，越界操作需要逐次审批；但文件沙箱不等于网络隔离。
3. **按 API 用量计费。** 它没有包月订阅兜底。新会话的系统提示、工具说明和 skill 清单都会形成固定的“入场费”，输出与思考 token 也会计费。
4. **前缀缓存非常重要。** 保持系统提示、工具顺序和会话前缀稳定，可以显著降低后续请求成本；在会话中途改配置、换人格或重排工具，可能破坏缓存。
5. **PTC 省的是中间过程。** PTC 让模型写一段程序批量调用工具，优势主要来自减少大量中间结果进入模型上下文，并不代表首轮提示天然更短或所有任务都更便宜。
6. **它能在运行时扩展自己。** 创造模式下，Agent 可以检查自身运行时、编写并挂载新工具，甚至在同一场会话中立即使用；但动态能力通常不会跨重启保留。
7. **skill、MCP 都由插件体系承载。** 插件是更大的扩展单元，可以注册工具、skill、MCP、模型适配器和其他服务；安装包不等于已经接入运行时。
8. **可追溯性是重要卖点。** 会话事件流记录模型请求、工具调用、审批和结果，适合回放、审计和定位问题。
9. **长期任务靠显式循环。** Harness 用目标、状态和循环机制驱动长任务，而不是只靠一句“继续做直到完成”的提示词。
10. **它仍是早期项目。** 接口可能发生破坏性变化，文档、发布包和仓库代码也可能短暂不同步；书中所有数字都应视为特定时间点的快照。

## 快速上手

准备好 Node.js 和 DeepSeek API Key 后，可用下面的命令启动网页版：

```bash
npx @deepseek-ai/dsh web
```

首次下载体积较大且可能没有明显进度提示。页面打开后，应先登记工作区，再确认使用的模式；模式只能在空白会话中切换。

建议从一个低风险任务开始，例如：

> 只读取当前工作区，概括目录结构和各文件用途，不要修改任何文件。

## 阅读提醒

- 原书描述的是 **DeepSeek Harness v0.1 开发者预览版发布时的状态**。
- 价格、版本号、工具数量、命令参数和接口都可能随项目迭代而变化，请以最新官方资料为准。
- API Key 会产生真实费用；敏感文件一旦被模型读取，相关内容可能被发送到远端模型服务。
- 开启完全放开的权限或创造模式前，应先使用隔离目录并确认风险。
